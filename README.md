# Equisharia-analytics-engine- is a Shariah-compliance screening tool that evaluates listed companies against AAOIFI investment standards. Using SQL, I calculated three core ratios from company financials — Debt-to-Assets %, Cash-to-Assets %, and Purification Ratio % — and flagged any company crossing the 33% debt or cash threshold as Non-Compliant. Out of 10 companies screened, 9 qualified as Shariah Compliant. The dashboard visualizes this screening summary, a sortable results table, and a debt-ratio comparison against the AAOIFI cap. This project combines my finance analytics training with practical SQL and dashboarding skills.
